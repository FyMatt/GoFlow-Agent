# 远程目标配置与验收

GoFlow 主程序仍在 Windows 本机运行。Linux 虚拟机或服务器是 SSH 执行目标，不要求把平台部署到远程系统。

## 配置目标

在资源页保存 SSH Target，包括目标标识、地址、端口、用户、凭据引用、固定主机公钥 SHA256 指纹和精确命令白名单。运行任务时选择同一目标；主机工具的 `target_id` 必须与任务目标一致。

当前 SSH 工具使用密钥认证，不接收模型生成的密码、交互式 sudo 或任意 Shell。用户只提供密码时，操作者可用它初次登录并添加专用公钥；保留原有 authorized_keys，私钥放在数据目录的受限秘密文件中，再使用 `secret://targets/<target-id>/private_key` 引用。不要把密码、私钥或解析后的凭据放入任务、资源 YAML、报告或 Git。

首次扫描得到的公钥只是候选身份，首次信任应结合虚拟机控制台或管理员信息核对。后续扫描和每次登录都必须匹配保存的指纹。主机重装或换钥后应重新核对，不要关闭 StrictHostKeyChecking 或自动信任新钥。

## 建议的只读验收

先按目标实际支持的命令配置最小白名单，例如：

```text
id
uptime
df -h /
free -m
systemctl --failed --no-pager
journalctl -u ssh --since -1hour --no-pager -n 80 -o short-iso
```

命令按完整文本匹配；未经配置的参数、拼接和其他命令会被拒绝。不同发行版的服务名、日志权限及命令可能不同，不能只照抄示例就认定覆盖完整。

使用 `remote-host-diagnostics` 技能，要求校验指纹、执行约定检查，将完整报告写入工作区指定路径并读回。核对时间线的真实工具结果、退出码、标准错误和截断状态，再核对报告是否区分事实、推断和未验证项。

免密 sudo 不可用、命令不存在、日志无权限或采集失败都是限制，不能写成检查通过。连接测试也会产生认证日志；应与本次验收的时间和来源对照，不能把验收活动直接写成入侵，也不能由此宣称没有其他攻击。

## Windows 客户端兼容与读取性能

部分 Windows 自带 ssh-keyscan 会宣告未实现的密钥交换算法，返回 unsupported KEX method。默认客户端遇到这一明确错误时，GoFlow 可使用标准 Program Files 下已安装的 Git OpenSSH 重试；显式指定的自定义客户端不被替换。未安装兼容客户端时会保留错误详情，需要安装受信任的更新版客户端或配置 `GOFLOW_SSH_KEYSCAN_CMD`。不修改服务器算法或放宽指纹检查。背景见 [Win32-OpenSSH 问题记录](https://github.com/PowerShell/Win32-OpenSSH/issues/2140)。

临时私钥目录在 Windows 使用受保护 ACL，仅当前用户可访问；POSIX 平台使用 0700/0600。权限设置失败会停止执行。只使用 chmod 不能可靠收紧 Windows 的继承权限。

SSH MCP 的环境白名单同时保留 USERNAME、USERDOMAIN、ProgramData、ProgramFiles、SystemRoot 和 USERPROFILE。过滤掉这些 Windows 运行时依赖可能造成客户端直接退出，或找不到兼容客户端；直接在终端执行成功不能代替经平台 MCP 的验收。

同一个 SSH MCP 进程最多缓存 64 个已匹配指纹的公开主机密钥，按地址、端口和固定指纹隔离，2 分钟到期；明确的主机密钥扫描仍访问目标。命令结果中的 `host_key_cached` 表明是否复用了公开密钥，不能解读为跳过验证：每次 SSH 登录仍严格检查该公钥。变更固定指纹不能命中旧缓存。

避免每条命令重复进行多种未认证握手；新版 OpenSSH 的 [PerSourcePenalties](https://man.openbsd.org/sshd_config#PerSourcePenalties) 可能因此暂时拒绝连接。不要通过关闭服务器保护解决客户端的重复探测问题。

## 验收层次

工具能连接、执行白名单并拒绝错误指纹，只证明连接与边界机制；完整模型报告、运维判断、安全无损核验和真实外部通知仍须分别验收。只读 SSH 诊断不代表已完成漏洞扫描或确认机器安全。平台本地事件 stored 也不代表外部 delivered。

## 运行恢复与变更证据

恢复输入、审批或继续执行时必须沿用持久运行记录中的目标，不能退回 local 或继承另一个任务的目标。重新选择目标应新建任务；恢复不扩大目标授权。真实虚拟机调查已覆盖授权输入门禁重启恢复，对其他目标的调用仍受边界检查。

大型材料优先提供索引和分开的原始日志，按需读取明确行段。完整哈希保留在证据索引，报告引用条目；报告中的哈希必须逐字核对，不能根据长度相近就认为有效。未执行通知节点且没有实际事件回执时，状态为未触发通知、未创建事件，不能因为通道为 local 就写 stored。深入调查新增预警时会走独立告警分支，初步已请求告警的不重复投递；失败仍进入质量门禁。

工作流在等待模型响应时重启，且没有结果未知的工具操作，会恢复为可继续的暂停状态；继续沿用原运行 ID 和已完成阶段。尚未产生模型正文不等于没有恢复上下文。结果未知的工具调用不会被当作可安全重放的模型等待。

报告标题兼容已定义的中文章节别名，业务字段仍按明确契约校验。补丁前后内容哈希及权限均相同时，不计为新增修改；真实权限变化仍计入变更。资源明确允许 go_race_unavailable 时，仅在证据确认工具链缺失且普通 Go 测试通过后降级，实际测试失败不会因此被放过，也不宣称 race 检测通过。
